检查项含义:

- SOLVABLE:起点可达终点。
- NO_SOFTLOCK:任何可达状态都仍能通关,不存在死局。
- NO_OVERLAP:任何可达状态下,没有两块可走砖投影到同一屏幕位置。
- RIDER_SAFE:移动机关后主角脚下的砖始终有效。

求解器的局限:它把机关当作在整数状态间瞬移,不检查机关转动途中的几何穿插;也不检查「非可走几何遮挡可走砖」这类纯视觉问题,后者靠下面的实机走查。
